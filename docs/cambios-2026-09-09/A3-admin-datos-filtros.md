# A3 · Datos para los filtros — Admin

Propietario: **Admin (Claude)**. El panel y su maquetación son de theme (`T3`); aquí solo los
datos que los filtros necesitan para existir.

## Facetas pedidas

| Filtro | Estado pedido |
|---|---|
| Colores | **Nuevo** — hace falta el dato por producto |
| Forma | Ochavada y Vega ya contempladas; **añadir Imperio / Viena** |
| Tipo de producto | Deja de ser faceta suelta: pasa a listado bajo “Decoración” en el lateral, con **todos** los productos y en **orden alfabético** |
| Novedades | **Nuevo** — dentro de disponibilidad o como filtro propio, lo que resulte más conveniente |
| Decorado | **Quitar** |

## Secciones

Como “sección” quedan **solo las colecciones**.

## Grupos con estilo propio

- **Novedades** y **Fin de existencias** salen como accesos por encima de las colecciones
  (ver `T3` para la posición exacta) → necesitan su colección/grupo en Admin.
- La lista de Novedades es la de `A2` (Áurea, Vela Aromáticas, Lapicero, Caja con 6 posavasos,
  Vaciabolsillo, Abanico).
- La lista de Fin de existencias es la del bloque homónimo de `A1`.
